# SlidesShare 🎓

Repositório dedicado ao armazenamento e à organização dos slides de apresentação das **Sprints acadêmicas da São Paulo Tech School (SPTech)**.

## 📚 Sobre o repositório

Este repositório reúne as apresentações desenvolvidas ao longo dos semestres da faculdade, servindo como um espaço centralizado para organizar e consultar os materiais utilizados nos projetos e nas entregas das Sprints.

## 🎯 Objetivo

- Centralizar as apresentações das Sprints acadêmicas.
- Organizar os materiais por semestre e projeto.
- Facilitar o acesso aos slides para consulta e revisão.
- Documentar a evolução dos projetos desenvolvidos durante a graduação.

## 🏫 Instituição
